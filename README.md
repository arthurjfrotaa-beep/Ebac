# Parquímetro - POO em JavaScript

Aplicação interativa de um parquímetro utilizando Programação Orientada a Objetos (POO) em JavaScript.

## Regras
- Menos de R$ 1,00: valor insuficiente.
- R$ 1,00 até R$ 1,74: 30 minutos.
- R$ 1,75 até R$ 2,99: 60 minutos.
- R$ 3,00 ou mais: 120 minutos (tempo máximo).
- O valor excedente é exibido como troco.

## Arquivos
- `index.html`: interface.
- `scripts.js`: lógica POO.
- `styles.css`: estilos.
